# 具体型号模块图片

图片与 OpenDB 参数数据分开存放。`manifest.json` 中的 `items` 以现有型号 ID 绑定图片；`assets` 保存本地文件、原图 URL、尺寸及大小。采集核对日期：2026-11-01。

图片分为四种，列表卡片和详情均明确标注：

- `model`：公开产品记录的完整型号或唯一料号匹配，或独立核对的具体产品图。BuildCores 匹配只使用同名记录和无歧义料号，不作模糊型号替换；不因此将社区数据标成厂家认证。
- `series`：可核对的同系列外观参考，具体颜色、轴体、容量、套装或修订版本仍需核对。
- `example`：GPU 芯片教学条目采用合作品牌成品卡举例，图片不定义芯片规格条目的成品尺寸、接口与功耗。
- `reference`：无可靠型号图片时，使用已收录的同类实物图片，**不是本条型号照片**。保留实际图片名称和原来源；`referenceProductId` 指向被引用的实物记录。耳机/麦克风/音箱、桌子/椅子、水冷/风冷等尽量按原类型区分；筛选器可只看型号图。

图片主要来自 BuildCores 公开产品页面；缺图项补充公开品牌官网、经销商与产品资料页。每条保留 `source`、`provider`、`imageName` 和匹配类型；文件级 `originalUrl` 保留实际下载地址。只整理图片身份和引用，不引入价格、库存、购买追踪参数或用户账户信息。

产品照片、商标及第三方宣传素材的权利属于各权利人。公开可读不等于开源授权，OpenDB 的 CC BY-NC-SA 4.0 数据许可不延伸到照片，本项目不为其重新授权。图片为本项目非商业学习展示使用，逐图给出来源；商用或进一步分发需另外确认许可。

WebP 缩略图保留比例，不生成虚构商品外观。在线版从本项目站点按需加载图片，不依赖第三方防盗链。单文件离线版本内嵌所有图片。更新清单后运行 `python build_pages.py`，开发入口的 `catalog-photos-data.js` 会同时重新生成。
