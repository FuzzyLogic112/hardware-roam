# 品牌地图图片与榜单

`manifest.json` 记录 158 个品牌的图片、360 条产品快照、源页面、原图地址和采集日期（2026-11-01）。WebP 是按比例缩小的本地学习用副本；没有把官网 Logo 或二维码充作产品照片。官网宣传展示图与具体产品图在页面中分别标注。

- 品牌展示图来自对应品牌官网，或 ZOL 产品页；VAXEE 为品牌图片，VXE 为 Meckeys 产品页，CyberPower 为 PowerPlanet 产品页。以清单中的逐图 `source`、`originalUrl` 为准。
- 热门顺序来自 ZOL/ZDC **关注榜**，不是销量、质量或性能排名；18 个品类各保留前 20 条。仅向用户展示筛选后的最多 10 条。
- 扩展坞与线材、桌面与人体工学暂无可核对的同类榜单，仍完整展示相应品牌图片；不编造名次。
- 高性价比候选：在同一来源品类的关注前 20 条中，保留有正数参考价、ZOL 用户评分至少 8/10 的条目，再按参考价升序、关注名次升序排序。这是预算与用户评分筛选，不是性能/价格测试。评分无样本量校正；不同代际、容量、用途仍需另行核对。
- 价格是来源页面的人民币**参考价快照**，不是实时成交价；缺失价格/评分保持空值，不当作零元/零分。
- 合并设备主题只提供部分子类的榜单（例如耳机主题的榜单不含音箱与麦克风）；页面逐类标明范围。

照片、商标与官网宣传素材的版权归原权利人。公开可读不代表开源授权；本项目不对图片重新授权，也不将 OpenDB 的 CC 许可延伸到照片。逐卡链接原始页面供核对；再分发、商用需单独确认图片许可。

构建时 `build.py` 将图片内嵌到单文件，开发入口使用相对本地图片，避免第三方图片防盗链或失效影响阅读。刷新数据时需同时更新 `manifest.json`、`brand-map-data.js` 与图片，再运行 `python build_pages.py`。
